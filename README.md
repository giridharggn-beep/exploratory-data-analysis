# Exploratory Data Analysis on Sample Superstore Dataset

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Sample Superstore dataset using Python, Pandas, and Matplotlib.

The analysis explores sales, profit, discounts, categories, regions, and sub-categories to identify useful patterns and insights.

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Key Analysis

- Category-wise sales and profit analysis
- Region-wise sales and profit analysis
- Sub-category sales and profit analysis
- Discount and profit analysis
- Identification of loss-making sub-categories

## Key Insights

- Technology had the highest total sales and total profit.
- Office Supplies had the highest number of records.
- The West region had the highest total sales and profit.
- Phones and Chairs were the top two sub-categories by total sales.
- Copiers had the highest total profit among the sub-categories.
- Tables, Bookcases, and Supplies were the loss-making sub-categories.

## Dataset

Sample Superstore dataset used for educational and analytical purposes.
